## SCR-TASK-003 タスク新規登録画面 / SCR-TASK-004 タスク編集画面（FUN-TASK-001 / FUN-TASK-002）

**画像ファイル：** `タスク管理画面.png`（上部・新規登録フォーム、右上・編集フォーム）

> SCR-TASK-003（新規登録）と SCR-TASK-004（編集）は同一レイアウト。
> 編集時は既存データがフォームに入力済みで表示される。

### レイアウト
```
[ タスク名はユニーク値 ]（注記）
┌──────────────────────────────┐
│  タスク名: [____________]    │
│  分類: [掃除][料理][洗濯][その他] │
│  開始日 時間  〜  終了日 時間  │
│  □繰り返し [繰り返さない▼]   │
│  報酬: 100円                  │
│  メモ: [新しい授業だよ！]     │
│  □即に完了にする              │
│  [ 登録 ]  [ 閉じる ]        │
└──────────────────────────────┘
```

### コンポーネント詳細

| 要素 | 種別 | バリデーション |
|---|---|---|
| タスク名 | テキスト入力 | 必須・ユニーク制約 |
| 分類 | トグルボタン群 | 掃除 / 料理 / 洗濯 / その他（単一選択） |
| 開始日時 | 日付・時刻入力 | 必須 |
| 終了日時 | 日付・時刻入力 | 必須・開始日時以降 |
| 繰り返し | チェックボックス＋セレクト | 「繰り返さない」チェック時は単発 |
| 報酬 | 数値入力（円） | 必須・0円以上 |
| メモ | テキストエリア | 任意 |
| 即に完了にする | チェックボックス | 任意 |
| 登録/保存ボタン | ボタン | — |
| 閉じる/戻るボタン | ボタン | SCR-TASK-001へ戻る |
