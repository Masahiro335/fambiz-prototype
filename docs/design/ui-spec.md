### 2.3 タスク管理（SCR-TASK）

| 画面ID | 画面名 | リリース区分 | 対象ロール | 概要 |
|---|---|---|---|---|
| SCR-TASK-001 | タスク一覧画面 | プロトタイプ | 全員 | 月カレンダー形式でタスクを表示。単日タスクはチップ、複数日タスク（start_time〜end_timeが日付をまたぐ）は連結バーで表示。ステータス多選択フィルタあり。タスクをクリックで詳細へ遷移 |
| SCR-TASK-002 | タスク詳細画面（子ビュー） | プロトタイプ | 子 | タスク名・分類・日付・繰り返し設定・報酬・メモを参照。「対応済」ボタンでステータス変更 |
| SCR-TASK-002b | タスク詳細画面（親ビュー） | プロトタイプ | 親 | タスク詳細の参照に加え、「編集」「削除」「戻る」ボタンで管理操作が可能 |
| SCR-TASK-003 | タスク新規登録画面 | プロトタイプ | 親 | タスク名（ユニーク制約あり）・分類・開始日時・終了日時・繰り返し設定・報酬・メモ・即完了フラグを入力して登録 |
| SCR-TASK-004 | タスク編集画面 | プロトタイプ | 親 | SCR-TASK-003と同レイアウト。既存タスクを編集 |
| SCR-TASK-005 | タスク検索画面 | プロトタイプ | 全員 | タスク名（キーワード部分一致）・分類（掃除/料理/洗濯/その他）・ステータス（完了/対応済/未対応）で絞り込み。検索結果をテーブルで表示。URL: `/tasks/search` |

**SCR-TASK-005 検索フォーム仕様：**

| フィールド | 種別 | 備考 |
|---|---|---|
| タスク名 | テキスト入力 | `keyword` クエリパラメータ。部分一致（ilike） |
| 分類 | セレクト | `category` クエリパラメータ。完全一致。掃除 / 料理 / 洗濯 / その他 / 全て |
| ステータス | セレクト | `status` クエリパラメータ。pending / reported / completed / 全て |

**SCR-TASK-005 検索結果テーブル列：**

| 列 | 説明 |
|---|---|
| タスク名 | 詳細画面（`/tasks/:id`）へのリンク |
| 分類 | カラーバッジ（掃除=青 / 料理=赤 / 洗濯=黄 / その他=緑） |
| ステータス | カラーバッジ（ステータスカラーコード準拠） |
| 報酬 | 報酬金額（円） |
| 期日 | JST 日付表示。未設定は「—」 |

- フォーム送信でURL検索パラメータを更新しサーバーサイドで再フェッチする
- 件数はテーブルフッターに「N件のタスクが見つかりました」形式で表示する
- 0件時は「検索結果が見つかりませんでした」メッセージを表示する

**タスクステータス一覧・カラーコード：**

カレンダー上のチップ・バーはステータス色で統一する。

| ステータス | 説明 | カラー |
|---|---|---|
| 未対応 (pending) | 登録済み・未着手 | グレー系 |
| 対応済 (reported) | 子が実行報告済み（承認待ち） | ブルー系 |
| 完了 (completed) | 親が承認済み | グリーン系 |
| キャンセル (cancelled) | キャンセル済み | レッド系 |
| 期限切れ (expired) | 期限を超過したタスク | レッド系 |

**SCR-TASK-001 カレンダーUI仕様：**

| 要素 | 仕様 |
|---|---|
| 表示単位 | 月カレンダー（日曜始まり7列グリッド） |
| 月ナビゲーション | 「< 前月」「次月 >」ボタン。現在月以外は「今月」ショートカットを表示 |
| 今日のハイライト | 当日セルに青背景、日付番号を青丸で強調 |
| ステータスフィルタ | 全ステータスのチェックボックス多選択。デフォルト全選択 |
| 単日タスク | 日付セル内にチップ表示（最大3件、超過分は「+N件」）。クリックで詳細へ遷移 |
| 複数日タスク | `start_time` と `end_time` が異なるJST日付のタスクを週行上部に連結バーで表示。開始端・終了端を丸め、週境界をまたぐ場合は直角で連結。複数バーが重なる場合はレーンを積み上げる |
| 色の基準 | チップ・バーともにステータス色で統一（カテゴリ色は使用しない） |
| タスク名表示 | バーの開始端にのみ表示。前週から続くバーは「…」を表示 |

### 2.4 目標管理（SCR-GOAL）

| 画面ID | 画面名 | リリース区分 | 対象ロール | 概要 |
|---|---|---|---|---|
| SCR-GOAL-001 | 目標一覧画面 | プロトタイプ | 全員 | 目標名・タスク名・ステータス・対象月・完了予定数・行動・条件（AND/OR）を一覧表示。フィルタ機能あり |
| SCR-GOAL-002 | 目標詳細画面 | プロトタイプ | 全員 | 目標の詳細表示。ステータスに応じてアクションボタンが変化（未挑戦/挑戦中/達成済/未達成） |
| SCR-GOAL-003 | 目標新規登録画面 | プロトタイプ | 親 | 目標名・タスク名（タスク検索モーダルで選択）・対象月・ボーナス報酬・担当者・目標回数・行動内容・AND/OR条件を登録。URL: `/goals/new` |
| SCR-GOAL-004 | 目標編集画面 | プロトタイプ | 親 | SCR-GOAL-003と同レイアウト。既存目標を編集。URL: `/goals/:id/edit` |

**SCR-GOAL-003 / SCR-GOAL-004 タスク紐づけ仕様：**

- 「タスク名」欄は読み取り専用の表示フィールド。直接入力不可。
- 「タスク検索」ボタンをクリックすると**タスク検索モーダル（SCR-TASK-005-MODAL）**が開く。
- モーダルでタスクを選択すると `task_id` と `task_name` がフォームにセットされる。
- 「✕」ボタンでタスクの選択を解除できる（`task_id = null` として送信）。
- 編集画面では既存の `task_id` に対応するタスク名をサーバーサイドで取得して初期値として表示する。

**SCR-TASK-005-MODAL タスク検索モーダル仕様：**

目標登録・編集フォームから呼び出されるモーダル。独立ページではなくオーバーレイコンポーネント（`components/TaskSearchModal.tsx`）として実装。

| フィールド | 種別 | 備考 |
|---|---|---|
| タスク名 | テキスト入力 | キーワード部分一致 |
| 分類 | カラーチップ（トグル） | 掃除=青 / 料理=赤 / 洗濯=黄 / その他=緑。選択中はリング強調 |
| ステータス | ラジオボタン | 全て / 完了 / 対応済 / 未対応 |

- 「検索」ボタンで `GET /v1/tasks` を呼び出し結果テーブルを表示する。
- 「クリア」ボタンで全フィールドと結果をリセットする。
- 行クリックでタスクを選択（選択行は緑ハイライト）。
- 「選択」ボタンで確定しモーダルを閉じる。未選択時は「選択」ボタンを非活性にする。
- 「戻る」ボタンまたはオーバーレイ背景クリックでキャンセルしモーダルを閉じる。
- 結果テーブル列：タスク名 / 分類 / ステータス / 期日 / 報酬。

**目標ステータス一覧：**

| ステータス | 対象操作 |
|---|---|
| 未挑戦 | 子が「挑戦する」ボタンを押せる |
| 挑戦中 | 親が達成/未達成を判定できる |
| 達成済 | 親が承認操作を行える |
| 未達成 | 終了済み（変更不可） |

## 4. 共通UI仕様

### 4.1 タスク分類カラー
- 掃除：ピンク系バッジ
- 料理：イエロー系バッジ
- 洗濯：ブルー系バッジ
- その他：グリーン系バッジ

### 4.2 ステータスバッジカラー
- 未対応：グレー
- 対応済：ブルー
- 完了：グリーン
- キャンセル：レッド

### 4.3 目標ステータスバッジカラー
- 未挑戦：グレー
- 挑戦中：ブルー
- 達成済：グリーン
- 未達成：レッド

### 4.4 評価（星）
- 1〜5段階の星評価
- 親のみ入力可能

### 4.5 繰り返し設定
- 「繰り返さない」チェックボックスあり
- チェック時は単発タスクとして扱う
