## 第2次フェーズ: 勉強・学習管理（FUN-STUDY）

> 「自己投資」の概念を学ぶ領域。MVPの家事管理と同一データモデルベースで拡張。

### 機能定義（案）

| 機能ID（案） | 機能名 | 概要 |
|------------|--------|------|
| FUN-STUDY-001 | 学習タスク登録 | 宿題・自主学習・資格勉強のタスクを登録する |
| FUN-STUDY-002 | 学習実績報告 | 学習完了をスコア・時間・内容とともに報告する |
| FUN-STUDY-003 | テスト結果記録 | テストの科目・点数・目標点を記録する |
| FUN-STUDY-004 | 学習カレンダー | 学習の実施状況をカレンダー表示する |
| FUN-STUDY-005 | 学習レポート | 月次の学習時間・スコア推移をグラフ表示する |

- [ ] 🟡 FUN-STUDY-001〜005 の要件詳細化
- [ ] 🟡 学習タスクの単価設定ルール策定（家事と同一か別体系か）
- [ ] 🟢 学習タスクのステータス遷移定義
- [ ] 🟢 NestJSに `study/` モジュール追加
- [ ] 🟢 Next.jsに `study/` ルート追加

## 第4次フェーズ: 報酬分析・全領域横断（FUN-ANALYTICS）

> 家事・勉強・部活の全報酬を横断した分析・可視化。

| 機能ID（案） | 機能名 | 概要 |
|------------|--------|------|
| FUN-ANALYTICS-001 | 全報酬ダッシュボード | 全領域の報酬推移を一画面で表示 |
| FUN-ANALYTICS-002 | 月次比較レポート | 前月比・前年同月比での比較分析 |
| FUN-ANALYTICS-003 | 目標達成率トレンド | 長期的な目標達成率の推移表示 |
| FUN-ANALYTICS-004 | 子どもの成長スコア | 独自の「成長指数」算出と可視化 |
