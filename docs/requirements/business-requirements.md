## 1. システム概要

### 1.1 背景

家庭内において、勉強以外の社会的な知識（働くこと・お金の仕組み）を教える機会や、子どもの努力を適切に評価し、コミュニケーションを取る機会が不足している。

### 1.2 目的

家庭内の活動を可視化し、**努力 → 評価 → 報酬（お小遣い）** の仕組みを提供することで、子どもの成長支援と家庭内コミュニケーションを促進する。

### 1.3 ステークホルダー

| ステークホルダー | 役割 | システムとの関係 |
|----------------|------|----------------|
| 親 | 利用者 | タスク登録・評価・おこづかい管理 |
| 子 | 利用者 | 家事タスク実行・実績登録 |
| サービス運営者 | 運営 | システム管理・ユーザー管理 |
| 開発者 | 開発 | システム開発・保守 |

### 1.4 用語定義

| 用語 | 説明 |
|------|------|
| FamBiz | 家庭内タスク管理・お小遣い管理サービス |
| タスク | 子供が実施する家事・お手伝いなどの活動 |
| 承認 | タスクや目標を承認する活動 |
| 月次評価 | 親が当月の総合評価をする活動 |
| 報酬 | 承認後に付与されるお小遣い |
| 目標 | 親が毎月設定するタスク目標 |
| 目標報酬 | 目標達成時の報酬（ボーナス） |
| 記事 | サービス運営者が作成するビジネス記事 |

### 1.5 前提条件

- 利用者はスマートフォンまたはPCから本サービスを利用する
- 親と子は同一家庭内で利用することを前提とする
- インターネット接続環境があることを前提とする
- 本サービスは家庭内教育支援を目的としたWebアプリとして提供する

## 3. アクター定義

### 親（Parent）

- タスクの作成・編集・削除
- タスク単価の設定（0円も可）
- 子の実績報告を承認または差し戻し
- マンスリーゴール（月次目標）の設定・承認
- 月次報酬の確定・支払い完了処理
- 家族グループへのメンバー招待

### 子（Child）

- タスクの一覧閲覧・選択・実行報告
- 自分の報酬履歴の閲覧
- 親が設定した目標への「挑戦する」宣言
- タスク実績の取り下げ（親承認前のみ）

### サービス運営者（Admin）

- ビジネス記事の作成・配信（本番用）
- お知らせの管理（本番用）
- ユーザー管理

## 5. 業務フロー

### 5.1 家事タスクの実行と実績登録フロー

```
[親] タスク登録（名称・単価・期限設定）
  ↓
[子] タスク一覧を確認 → タスクを選択して「完了報告」
  ↓ （承認待ち状態。同一タスクへの重複報告は不可）
[親] 報告を確認 → 承認 or 差し戻し
  ↓ 承認時：報酬が「確定報酬」として計上
  ↓ 差し戻し時：子は再度実行・報告可能
[親] 月末に「支払い完了」処理 → 累積報酬リセット
```

### 5.2 目標登録と目標挑戦フロー

```
[親] マンスリーゴール登録（定量 or 定性 + ボーナス金額）
  ↓
[子] 目標を確認 → 「挑戦する」ボタンを押下（目標達成率に反映）
  ↓
[子] 月中: タスク実行を継続（ダッシュボードで進捗確認）
  ↓
[親] 月末: 目標達成判定（達成 / 未達成）→ 承認
  ↓ 達成時：ボーナスが月次報酬に加算
  ↓ 未達成時：ボーナスなし
[親] 支払い完了処理
```

## 6. 業務ルール

### 6.1 ユーザー・権限に関するルール

- **家庭単位の紐付け:** 親に対して複数の子を紐付けられる。子は複数の家庭に属することはできない。
- **操作権限:**
  - 親のみ: タスク作成・編集・削除、単価設定、実績の承認・差し戻し、月次報酬の確定
  - 子のみ: タスクの実行報告、自分の報酬履歴の閲覧
- **認証:** 親と子でログインアカウントを分ける（セキュリティの観点）

### 6.2 タスクに関するルール

- **単価設定:** タスクには必ず「単価（円）」を設定する。0円（ボランティア）の設定も可。
- **タスクの有効期限:** 単発タスクは設定された期限を過ぎると自動的に「期限切れ」となり、報告不可。
- **重複報告の禁止:** 同じタスクに対して承認待ちの間は重ねて報告できない。

### 6.3 ステータス遷移と承認に関するルール

- **承認による報酬確定:** 親が「承認」を行った瞬間に報酬額が「確定報酬」として計上される。
- **キャンセル:** 子は対応済みタスクを取り下げ可能（「キャンセル済」へ遷移）。ただし親の承認後は取り下げ不可。
- **キャンセル取消:** 子はキャンセル済みのタスクを取り消して「未対応」に戻すことができる。ただし期限切れ・完了済みタスクは不可。

### 6.4 報酬計算に関するルール

- **集計期間:** デフォルトは毎月1日〜末日。
- **端数処理:** 計算上の小数点以下は切り捨て。
- **支払い完了:** 親がシステム上で「支払い完了」処理を行うと累積報酬額がリセット（既読化）される。

### 6.5 目標設定（マンスリーゴール）に関するルール

- **目標の種類:**
  - 定量目標（回数）: 例「月に15回以上、ゴミ出しをする」
  - 定性目標（行動）: 例「自分から進んで挨拶をする」「靴を揃える」
- **目標達成インセンティブ:** 設定時に追加報酬（ボーナス）を設定可能。通常タスク報酬とは別集計。
- **目標挑戦:** 子が「挑戦する」ボタンを押すことで目標を受諾（目標達成率に反映）。
- **進捗の可視化:** ダッシュボードでプログレスバー等による達成率表示。
- **評価と振り返り:** 月末に親が達成/未達成を判定し承認。
