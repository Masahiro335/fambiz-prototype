# /task-status

**引数**: `$ARGUMENTS`（任意。フェーズ番号、例: `0`、`1`。省略時は全フェーズ表示）

`docs/tasks/mvp-tasks.md` の実装進捗を集計し、次に着手すべきタスクを提示します。

---

## 実行手順

1. `docs/tasks/mvp-tasks.md` を読み込む
2. 引数でフェーズが指定された場合はそのフェーズのみ、省略時は全フェーズを対象にする
3. 各フェーズごとにタスクを集計する：
   - `[x]` = 完了
   - `[~]` = 作業中
   - `[ ]` = 未着手
4. 完了率（完了数 / 全タスク数）を計算する
5. 🔴ブロッカーの未完了タスクを抽出する
6. 次に着手すべきタスクを以下の優先順位で推薦する：
   1. 🔴ブロッカーかつ `[ ]` のタスク
   2. 依存するブロッカーがすべて `[x]` になった 🟡並行可能タスク
   3. 🟢後回し可タスク
